## 新增文件分流规则

新写文档按下表落位（与 [DOCS-STRUCTURE.md](DOCS-STRUCTURE.md) 同一口径）：

| 你想写的东西 | 落位 |
|---|---|
| 新计划 / 提案（在流） | `docs/plans/`（`YYYY-MM-DD-<topic>-proposal.md`） |
| 新提案（非计划流程） | `docs/proposals/` |
| skill 说明（今后落位） | `docs/skills/`（目录建立后新文件进这里；存量平铺文件暂不迁移） |
| 历史归档 / 完成使命的旧文档 | `docs/archive/`（不删除） |
| 日期前缀的评估归档（既有惯例） | `docs/` 顶层平铺，`YYYY-MM-DD-` 前缀（J15 判） |
| 常驻参考（SOP / 地图 / 台账） | `docs/` 顶层平铺，不带日期，名字即定位 |
