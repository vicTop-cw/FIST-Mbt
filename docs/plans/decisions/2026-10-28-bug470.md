# 裁决：BUG-470 —— S3 认证默认策略

## 决定

采用 **策略 B（默认降权）**。

## 落地方式

1. 新增 `FIST_AUTH_MODE = "off" | "soft" | "strict"` 开关，**首次默认 `off`**
2. 观察一周后默认值 flip 到 `soft`（此时「无公钥者一律按 Executor 算」生效）
3. 补「客户端自举」文档：每个调用方启动时自己生成密钥对并登记（服务端不碰私钥 —— 服务端能批量生成 = 能替任何人签名 = S3 归零）

## 为什么不是 C

`strict` 会让 56 个调用方**立刻全部失败**，而批量登记路径不存在 ⇒ **无恢复手段**。

## 验收条件

- 开关三个取值都有行为锁
- `off` 时行为与修前逐字相同（零回归）
- 回滚实测 <10 秒（停 server → 改 env → 重启）
