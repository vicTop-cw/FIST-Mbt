**关键经验（MoonBit JSON）**：`Json::parse`/`Json::from_string` **不存在**；核心包 `json` 的入口是包级 `pub fn parse(StringView, max_nesting_depth?) -> Json raise ParseError`（**raises**，不是 Result）。用法：`moon.pkg` 里 `"moonbitlang/core/json" @json` 加包别名，然后 `try { @json.parse(text) } catch { e => Err(e.to_string()) }`。别名 `@json` 不影响 `Json::object(...)`/`Json::Array` 等类型级构造。
