### 拓扑教训（重要，防误判）
- **origin 出现 force-update**（`bce150b...4f96ef5 (forced update)`，外部 GitHub→gitcode 同步链所为，非我）：它把我在 GitHub 上的分步提交重写成一个 add-only 合并提交。应对：fetch 后先 `git log HEAD..origin/master` + `git show --stat` 看清对方重写了什么，**确认其内容 = 我的修复（只是打包方式不同）才 merge**；merge 只涉 attest.yml（工作树该文件干净）不碰并发会话 141 个未提交文件；合并后 fast-forward push，绝不 `--force`。
- run#8 的同名 artifact 重复正是这次 merge 的产物（双方各带一条 upload-artifact）——**同步链合并不是无风险的**，合完必须重验调用面。
- pwsh 里 `curl -d '{\"ref\":...}'` 转义失败导致 dispatch 静默没生效（轮询 6 分钟全在看旧 run）——发 JSON body 用 `Invoke-WebRequest -InFile <ascii file>` 可靠。
- Windows 下 python print 中文+`↔` 会 GBK 崩——脚本开头 `sys.stdout.reconfigure(encoding="utf-8")`。
