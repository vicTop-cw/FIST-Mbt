## 2. BUG-50：`check_test_sync` 判据重设计（脚本层，整段重写）

旧形状「实测数出现在指定 4 份文档」= 存在性检查，结构上测不到"第 5 份写着别的数"
（上一轮 `docs/agent-map.md` 写 316 而实测 406，就是这么长绿的；该轮只改了文档、把缺口如实留给下一轮）。

新四条判据（`scripts/check_test_sync.py`）：

- **R1 反向全量扫**：现状面 **99 份** `.md`（README / README_EN / AGENTS / USAGE / BACKLOG / 规范 /
  `docs/**` / `scripts/*.md` / `templates/*.md` / `plugins/**`）。声明按**窄口径**四种形状识别：
  `N/N` 等值对、`N 项|个|条 [测试|用例] 全绿|通过|passed`、`total=N`、日志回显 `Total tests: N, passed: N`。
  不等值对**不算**声明——否则 `105/104`（缺陷引文）、`1986/1997`（论文年份）、`22/30`（缺陷编号）全是误报。
- **R2 must-carry**：5 份现状文档必须携带实测数（不许用"把声明删掉"消解违例）。
- **R3 防空转**：现状面一条等于实测的声明都没有 ⇒ 红。正则饿死 / 文档改写法 ≠ 没有问题。
- **R4 豁免双向**：历史数与别的 target 必须逐条点名 `(文件, 数, 理由)`，共 7 条；
  **条目失效也判红**（白名单只进不出就是下一个谎言）。
- 历史记录按**路径类别**整面豁免：`memory/`、`reports/`、`CHANGELOG.md`、`docs/superpowers/plans/`、
  文件名以 `YYYY-MM-DD` 开头的文件——改写它们等于伪造历史。
- `--selftest`：**8 个违例变体**各命中自己指名的那一条（含"自洽的谎"型：实测数整批改写成 500 并同步扩
  豁免表，仍被 R2 抓住；以及"不得误抓引文/年份/编号"的反向对照）。末行计数由 `run_case` 累加，不手写。
  已挂 CI：真判据 + selftest 两条步骤（步骤名同时改掉旧的"四文档"口径）。

首跑活证据（`--total 439`，红 3 条）：`docs/evolve.md:146`（148/148）、`docs/atgc-selfdrive-demo.md:93`
（191/191，原文用词还是"**当前**"）——两份都在旧白名单之外。回写用 `temp/bump_claims_r3.py`
（数字只从实测日志解析，且复用守卫自己的 `collect_claims` 定位声明行；豁免位一条不动）。

**同轮又抓到一个更基本的洞**：判据写完才发现**扫描面本身漏文件**——`README_EN.md` 整面停在
