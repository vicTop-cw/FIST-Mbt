# 调研档：四金信号健康巡检 health_check（R102 候选 · 2026-09-26）

> 来源（WebSearch 实检）：Google SRE Book（Beyer et al. 2016，《Site Reliability Engineering》「Monitoring Distributed Systems」章）四金信号 = **latency / traffic / errors / saturation**——"若只测四个数，就测这四个"；要点：latency 用百分位（p50/p95/p99）而非均值（均值掩盖尾部），成功与失败延迟分开跟踪；**saturation 是先行指标（leading indicator，80% 预警）**，其余三个是滞后指标；traffic 给其他信号提供上下文（10x 负载下的错误率含义不同）；OpenObserve/ScopeForged/Autoheal 2026 综述同口径（saturation = 队列深度/容量占用）。
> 前置：R68 project_health（健康卡：六类计数 + 等级）。本档为 BACKLOG P2「多维度健康指标：除存活外检查 CPU/内存/任务积压/最近成功（4 类检查）」。

## 一、核心矛盾（为什么需要四金信号）
- R68 project_health 给"一个等级 + 计数"，但缺**维度分解与先行预警**：积压（待领取）是最接近"饱和"的**先行指标**——系统在"彻底坏掉"之前先积压；错误率（已打回/已暂停占比）是**滞后但最疼**的信号；活跃（in_flight）是**流量上下文**；完成周期（created_at→updated_at）是**延迟**。
- SRE 框架说：单信号不足，四信号合看才有完整健康图景——与"更好的 AI 项目管理工具"的"一眼看全项目健康"叙事直通（project_health 升级为四金巡检）。

## 二、拿来主义落地（fist-mbt 版蒸馏）
| 外部信号 | fist-mbt 落地设计 |
|---|---|
| Latency（百分位，非均值） | 最近已完成任务的平均完成周期 p50/p90（created_at→updated_at 秒，复用 @ops.iso_to_secs），完成数 <3 记 insufficient |
| Traffic（需求上下文） | 活跃 in_flight 任务数（执行中+已领取+拆分中）+ 当前待领取 |
| Errors（失败率） | 失败率 =（已打回+已暂停）/ 任务总数 |
| Saturation（先行指标，队列深度） | 积压率 = 待领取 / 总数——**先行预警**（SRE：系统先积压后坏） |

## 三、设计要点（复用避免造轮子）
- **复用**：`engine.list_all()` 单次取全任务（R9/R44 同款）；状态判定 `is_*` 族（R88/R98/R100 同款）；`@ops.iso_to_secs` 时间解析（R90 heartbeat 同款）；难度/健康聚合模式参照 project_health（R68）。
- **数据流**：`health_check(ns?)` →
  1. 全任务按状态分桶（in_flight / ready / done / blocked / archived）；
  2. latency：已完成任务 created_at→updated_at 秒差排序取 p50/p90（<3 条 insufficient）；
  3. errors：blocked/total 率；saturation：ready/total 率（先行）；
  4. traffic：in_flight 数 + 近 24h 完成数；
  5. 单信号 verdict：saturation>0.5 attention（先行预警）/ errors>0.3 attention / latency insufficient / traffic=0 idle；grade = 最差信号（healthy/attention/stalled/idle）。
- **零回归**：新工具独立注册（97→98，看板组 19→20），不改 project_health/status_summary 既有语义；纯计算只读不写库。

## 四、验证草案
- 单测：饱和积压>0.5 → attention（先行预警）/ 错误率>0.3 → attention / 全部完成 → healthy / 空仓 → idle / 完成<3 → latency insufficient / ns 过滤。
- E2E：award_demo 加 R102 段（health_check 打印四信号 verdict）；守卫族 + cleanup CLEAN。
