## 一、论文/经典信号

| 信号 | 核心 | 对 fist-mbt 可借力点 |
|---|---|---|
| **Phi Accrual Failure Detector**（Hayashibara et al., IEEE/DSN 2004）| 按心跳间隔历史（滑动窗口均值 μ + 标准差 σ）建模到达分布，φ = -log10(P(心跳晚于 elapsed 到达))；φ 随静默时间单调增，跨过阈值（原论文默认 8）判"疑似宕机"。σ=0 回退指数分布。**Cassandra / HBase 生产采用** | 把 watchdog/heal 的"固定 timeout_sec"升级为"概率怀疑度 φ"——心跳节奏越快、越久没来才值得怀疑，而非拍脑袋固定超时；有论文锚点 + 工业采用证据 |
| （对照）Fixed/Adaptive timeout | 固定 N 秒 / 按均值×倍数 | 现有 watchdog 的 timeout_sec 即 fixed；φ 是其概率化升级，可平滑替换 |

## 二、蒸馏结论（可落地性）
1. **φ 计算原语 = 本轮落地目标**（纯计算、可测、可复现）：
   - 输入：intervals（心跳间隔秒数组）+ elapsed（自上次心跳秒数）+ threshold（默认 8）；
   - 计算：窗口 μ/σ（Bessel 校正）→ z=(elapsed-μ)/σ → 正态右尾 Q(z)=Φ(-z)（|z|<3 用 A&S erf 近似，|z|≥3 用渐近展开保深尾部精度；core 无 sqrt 用牛顿法自实现）→ φ=-log10(Q)；σ≈0 回退指数 φ=elapsed/μ·log10(e)；
   - 输出：{ verdict: insufficient|healthy|suspect, phi, mean, stddev, window, threshold }。
2. **后续候选（非本轮）**：心跳间隔历史持久化（store 现仅 last_seen，无间隔史）→ watchdog 端到端接入 φ 判活（替换 timeout_sec 分支，默认关闭零回归）。
3. 与既有看护族关系：phi_accrual = 判活信号源升级，heal/watchdog 消费它可自动"越久越怀疑"。

## 四、落地设计草案：`phi_accrual` 工具（R89）
> 纯计算、无副作用、零新表。原则：复用既有（json/engine 包），不新造轮子。
- **位置**：engine 包自由 pub 函数（同 extract_difficulty 模式）+ server 注册（运维组，90→91）。
- **测试**：①σ=0 指数回退（固定 5s：elapsed 5s→φ≈0.434 健康 / 100s→φ≈8.686 怀疑）；②正态建模（μ=10/σ≈3.54：z=5→φ≈6.5 健康 / z=6→φ≈9.0 怀疑）；③单调性（elapsed 越大 φ 越大）+ 空历史 insufficient。
- **口径**：默认关闭接入 watchdog（φ 只作判活信号源，heal 消费留后续），既有固定 timeout 行为零回归。
