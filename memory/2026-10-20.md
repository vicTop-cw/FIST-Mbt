## 12:54Z — BUG-330 新版 moonfmt 把 Int 规范化成 Int32（OPEN，工具链面）

逐文件 `moonfmt.exe <f> -o out` 对照后发现：17 个改动文件里唯一的格式差异就是 `Int`→`Int32` 的签名行；
`.mbti` 里那 24 处 `Int`→`Int32` 同源。推论：`moon fmt --check` 在这一版对**整仓**存量拼写系统性红，
把它绿是一次独立的全仓 `moon fmt`，不属本单边界。
副作用一条要记住：上一轮"16 个文件 fmt 幂等通过"的成立前提，是先把 `Int` 改成了 `Int32`——
那 28 行不属于 API 适配，已从提交剔除；revert 后 `moon check --target js --json` 仍是 0 error（逐项读数不变），
证明它语义惰性。
