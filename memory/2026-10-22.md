
## R70 `fix/whisperer-selftest-and-scan-gitdir`（agent-skill-docs）—— 风语者自检在 worktree 里恒红：根因不在它自己

- 上手先跑 master 上最新的 `whisperer.py --self-test`（TASK-009，别的线刚落的件）⇒ **rc=2**，
  红在 `G1 fist-gate.py --scan rc=1`。**一个工具的自检在它自己的仓库里就是红的**，这条线显然没被在
  worktree 里跑过。
- 根因（三层，逐层剥）：① `fist-gate.py --scan` 原实现用 `Path(root)/".git"/"fist"/...` 建输出目录，
  而**在 git worktree 里 `.git` 是文件**（gitdir 指针）⇒ `FileNotFoundError`；② 未捕获异常让退出码
  变成 1，于是下游把它读成"判据红了"（**异常退 1 冒充判据红**，与 BUG-303 同族的坑）；③ whisperer 的 G1
  只印 `rc=N` 不说原因，且 `run()` 不传 `cwd` ⇒ 在别的目录跑自检还会"找不到 scripts/fist-gate.py"，
  两件事叠在一起，红得没有信息量。
- 修法：`fist-gate.py` 改用 `git rev-parse --absolute-git-dir`（取不到 rc=2 拒绝"在错位置写任务"）；
  whisperer G1 固定 `cwd=ROOT`、并把结果分**三档**：绿 / **DEGRADED(rc=2) 单列** / 红带末行+提示
  （DEGRADED 既不是绿也不是"你坏了"——把它算绿会掩盖下游故障，算红会让人去翻本脚本的源码）。
- 顺带统一旗标：本工具只认 `--self-test`，而全仓惯例是 `--selftest` ⇒ 任何"对所有尺统一跑 --selftest"
  的自动化都会在它身上拿到 argparse rc=2。现两个都收（同一 dest），行为一致。
- 签收：`--self-test`/`--selftest` 均 **rc=2 → 0**；`fist-gate.py --scan` 在 worktree 里 **rc=0** 且 yaml
  落到真实 gitdir；从 `C:\` 跑 whisperer 自检仍 **rc=0**（证明 ROOT 修正真的生效，不是碰巧）。
- 方法论沉淀：**"自检红"必须先分清「我没量到」「下游坏了」「我坏了」三档**。只印一个 rc 的做法会让
  读者把三种混成一类，最后就是没人读红——本项目反复出现的那条主线。

  而 `check_demo_isolation.py` 只钉 `FIST_DB_PATH`（库改道）一个方向，钉不到「文件面被写脏」。
- 本尺只回答一个问题：**被包住的那条命令跑完之后，git 跟踪面与未跟踪面变没变**。它不判那条命令成没成功
  （那是那条命令自己的契约），所以被包命令的退出码只回显在 `WRAPPED_RC=<n>` 行，**绝不借用本判据的退出码字母表**——
  `sys.exit(p.returncode)` 那类透传正是 `check_exit_code_contract`（BUG-369）点名抓的不透明出口。
- 快照 = `git diff HEAD` 逐文件切块哈希 + `git ls-files --others --exclude-standard` 清单。**刻意不看 mtime**：
  只被 touch 而内容未变不算污染（盘上对照 T7 实测 rc=0 clean）；反之状态字母不变、内容又插一份（R98 那一形）必须抓得到，
  所以按 diff 切片取哈希而不按 `git status` 的行取（盘上对照 T3 实测 rc=1 `POLLUTED diff-content`）。
- 五条承重规则 `diff-added` / `diff-content` / `diff-cleaned` / `untracked-added` / `untracked-cleaned`；
  两条 `UNDIRTY` 档不删——命令把「本来就脏」的文件洗掉同样是改了工作树状态，该点名而不是静默（T4 实测 rc=1）。
- 退出码：0 两面未变 / 1 检出变化并逐条点名 / 2 判据无法自证（不在 git 仓、取不到 git、被包命令根本没起来＝什么都没测到，
  空扫描必自拒不冒用 1）/ 4 尺子自己坏了（`RULER BROKEN`）。
- 读数：`--selftest` **9/9 rc=0**（合成违例必红 5 + 干净反向对照 1 + 规则失明对照 3）；本仓裸跑 **rc=0**；

  T5 干净 rc=0 / T6 被包命令自退 3 只回显 `WRAPPED_RC=3` 且本尺 rc=0 / T7 只 touch rc=0 / T8 非 git 仓 rc=2 / T9 命令起不来 rc=2。

  `check_scripts_index` **rc=1，红的是 3 条预存项**（`check_bug_refs.py` / `fist-pr-automator.py` / `fist-task-pool.py`，
  都不是本单元的文件，本尺已在 README 登记）；`run_guards.py --list` → 尺 90 把 / CI 面 28 / 电池面 90 / 缺执行面 0，
