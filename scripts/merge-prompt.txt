# MoonBit 高频坑（必须遵守！）
1. String::split() -> Iter[StringView]，元素是 StringView 不是 String！
2. StringView 上没有 to_lowercase() / substring() / index_of() / to_string()！
3. StringView -> String 用 .to_owned()（.to_string() 是 deprecated 别名）
4. Int/Status enum -> String 用 .to_string()（Show trait，不影响）
5. named parameter 波浪线 ~ 只在函数调用参数位置，局部变量不带
6. 验证任何 API 用 moon ide doc "关键词"，别猜

# 硬规则（违反即打回）
1. 不许直接 commit main——先在 feature/ 或 fix/ 分支 commit，解完冲突 moon check 0 errors 后再合入 main
2. moon fmt 先跑——所有 .mbt 文件改动必须 moon fmt
3. moon check 0 errors 是合入硬门——有 error 不许 push
4. 每次合入前跑 whisperer --fast——确认 HEAD 没漂移
5. Python 可用于风语者/脚本，主语言必须 MoonBit

Phase 2（慢，每条约 3-5min）：
  foreach branch in MERGE-CODE 列表：
    git checkout -B work/merge-one-branch gitcode/main
    git fetch gitcode $branch
    git merge gitcode/$branch  # 预期冲突
    # 手动解冲突：保留当前 HEAD 的新代码 + 合并分支的新增逻辑
    # src/ 用当前 HEAD 优先，scripts/docs 取较新版本
    moon fmt
    moon check --target js  # 必须 0 errors
    git add -A
    git commit -m "Merge $branch: 手动解冲突合入"
    git checkout main
    git merge work/merge-one-branch
    moon check --target js
    git push gitcode HEAD:main HEAD:master
    python scripts/whisperer.py --fast  # 确认 HEAD 没漂
