## 规定输出（严格照此执行）

先输出**恰好一行** JSON，前缀固定为 `SCORE_JSON:`，`reason` 用中文 ≤150 字并引用快照证据，**禁止自吹/空泛**：

```
SCORE_JSON:{"p1":0.xx,"p2":0.xx,"p3":0.xx,"verdict":"pass"|"fail","reason":"..."}
```

然后（可另起一行）补充 ≤150 字理由。

**全档达标口径（verdict 判定唯一依据）**：
- `p1 >= 0.70 && p2 >= 0.85 && p3 >= 0.97` → `verdict="pass"`
- 否则 → `verdict="fail"`

> 目标提档（2026-09-24 /goal）：一等 70% / 二等 85% / 三等 97%。

`reason` 必须说明：给分依据的证据/外推点 +（若 fail）缺口在哪一档、卡在哪个维度。
